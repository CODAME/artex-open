How time is mapped in this prototype +

Both paths capture the same 320 × 200 input at 24 fps. Tap i samples offset + round(i × depth / captureCount) frames ago, with i starting at 1. Enabled taps are averaged, then mixed with the present using Blend. Missing history uses the oldest available frame; with no history, the present is shown.

Echo stores up to 145 frames. The p5.js buffer stores up to 241 frames and wraps its write index; its extended mode allows 12 taps across 192 frames. This is an illustrative control mapping, not a claim about ARTEX's internal delay formula. More taps and longer histories remain limited by device memory.
